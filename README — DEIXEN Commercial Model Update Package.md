## Key assumptions recorded

- Explore is a limited, genuine learner-operated basic booking practice experience, not just a video/demo and not an independent assessment.
- Ghost's scripted demonstration on a demo booking is distinct from hands-on learner Terminal practice.
- Full Access should contain the coherent core learning experience; the core assessment/evidence promise should not be fragmented into arbitrary paid add-ons.
- The standard learning-access duration should be derived from realistic learner-hours. Three months is a candidate standard duration; six months is an extended option only if the actual workload and weekly study assumptions support them.
- Egypt price hypotheses: EGP 1,299 for one month, EGP 3,699 for three months, and EGP 6,499 for six months.
- USD 25/month is a proposed international reference, not a mechanical currency conversion or an approved global price.
- A working professional may voluntarily renew for continuing development after employment, provided the offer supplies real recurring value.
- Learning success and customer retention/revenue must be measured separately.
